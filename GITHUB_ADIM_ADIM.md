# GitHub'a yükleme — kısa yol

1. GitHub'da yeni bir repository oluştur.
2. Repository adını örneğin `telkin-game` yap.
3. README / .gitignore / license ekleme kutularını ilk oluştururken boş bırak; projede zaten dosyalar var.
4. Repository açılınca **Add file → Upload files** seç.
5. Bu ZIP'i telefonda/bilgisayarda aç ve ZIP'in içindeki **bütün klasör ve dosyaları** yükleme alanına bırak.
   - `index.html` repository kökünde olmalı.
   - `TELKIN_v5_0_MODULER_GITHUB` adlı üst klasörün kendisini ikinci bir klasör olarak yükleme.
6. Commit message: `TELKIN v5 modular initial upload`
7. **Commit changes**.
8. Settings → Pages.
9. Source: **Deploy from a branch**
10. Branch: `main`, folder: `/ (root)`, Save.
11. Birkaç dakika sonra GitHub Pages adresi oluşur.
12. Ana sayfa açılmazsa ilk kontrol: repository kökünde gerçekten `index.html` var mı?

Detaylar sohbet içindeki adım adım yönergede açıklanır.
